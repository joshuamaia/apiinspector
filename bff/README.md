# API Inspector — BFF (NestJS)

Secure HTTP proxy used by the API Inspector frontend. See the [main README](../README.md) for architecture, configuration and security details.

```bash
npm install
npm run start:dev     # http://localhost:3000/api
npm test              # unit tests
npm run test:e2e      # integration tests (local controlled HTTP servers)
```

Configuration: copy `.env.example` to `.env`.
